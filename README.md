# Jadeite Systems · Surveyor portal

Clickable prototype of the **Surveyor portal** for Jadeite Glazing — what a surveyor sees. Same design system and customer records as the Office Admin and Sales portal.

Signed in as **Priya Shah**. Sign-in code: **482193**.

## Screens
| Area | Screens |
|---|---|
| Start | Sign-in with 6-digit code · 3-step welcome tour |
| Today | Needs your attention · next visit · today's route with drive times · coming up · from the office · recently submitted |
| Final surveys | List (to do, today, not finished, move asked, submitted, customer not in) · survey visit: details, measure every item, site checks, photos, sign and submit, report, history |
| Inspections | Aftercare and snag inspections · findings, fix, part, photos, signature |
| My calendar | Week and list view · time off |
| Messages | Message the office · email the customer |
| Settings | Profile, area and working days · notifications · Outlook and Framepoint · sign-in |

## Run
`pnpm install` then `pnpm dev`.
